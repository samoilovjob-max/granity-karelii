# Граниты Карелии

Сайт granit-karel.ru: о компании, виды гранитов, строительная и мемориальная продукция, галерея, калькулятор массы и контакты.

Шрифты: Manrope и IBM Plex Mono. Цвета: `#233B46`, `#C66A42`, `#F1F1EE`.

## Калькулятор

Масса прямоугольной плиты:

`длина × ширина × толщина × справочная плотность × количество`

Размеры переводятся в метры. Плотности в калькуляторе — справочные, для оценки логистики.

## Локально

```bash
node js/calculator.test.js
python3 -m http.server 8080
```
